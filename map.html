Where the labels are

Where the samples actually are, from each dataset's own index files: 74 datasets with sample or tile locations, 36 with only named sites or a bounding box, 8 with no public location data. The Countries view shades each country by how many datasets name it in their documentation.

Coverage

  • Global datasets are counted for every country. Regional datasets and those with no documented geography are listed beside the map. Global coverage is taken from each dataset's documentation, not from its actual sample locations.
  • Samples view: points are chip, tile, field or site centroids taken from each dataset's own metadata (index files, STAC catalogues, GeoTIFF headers or coordinates encoded in file names), never from the paper's prose. Up to 3,000 points are shown per dataset; the panel states the full count. Datasets distributed only through Google Drive, Kaggle or registration, or released without georeferencing, show named sites or a bounding box instead. Each point set names its source file and method; the scripts are in scripts/footprints/.
  • Boundaries: Natural Earth 1:110m.
